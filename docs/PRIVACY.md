# Политика конфиденциальности Slovo

Дата вступления в силу: 8 сентября 2026 года.

## Какие данные обрабатываются

Slovo обрабатывает адрес электронной почты, хеш пароля, содержимое пользовательского словаря, учебный прогресс, настройки приложения и технические данные, необходимые для авторизации и работы сервиса.

Исходные пароли, коды подтверждения, токены восстановления и ключи интеграций не хранятся в открытом виде.

## Для чего используются данные

Данные используются для:

- создания и защиты аккаунта;
- синхронизации словаря, настроек и прогресса между устройствами;
- построения очереди интервальных повторений и статистики;
- отправки писем подтверждения и восстановления доступа;
- выполнения функций, явно запрошенных пользователем.

## Передача третьим сторонам

Для доставки служебных писем используется Resend. Для проверки и загрузки новых Android-версий приложение обращается к публичному GitHub Releases API. Эти провайдеры могут получать стандартные технические данные запроса, включая IP-адрес. Инфраструктурные провайдеры могут обрабатывать технические данные исключительно для размещения и работы сервиса. Slovo не продаёт персональные данные и не использует их для рекламного профилирования.

## Хранение и защита

Данные передаются по HTTPS. Доступ к производственной инфраструктуре ограничен. Данные хранятся столько, сколько существует аккаунт или сколько требуется для обеспечения безопасности и выполнения применимых требований.

## Управление данными

Пользователь может изменить пароль и удалить аккаунт в профиле приложения. При удалении аккаунта связанные пользовательские данные удаляются или обезличиваются в соответствии с техническими и правовыми требованиями.

## Дети

Приложение не предназначено для самостоятельного использования детьми младше возраста цифрового согласия без разрешения родителя или законного представителя.

## Изменения политики

Актуальная версия политики публикуется в этом репозитории. Существенные изменения сопровождаются обновлением даты вступления в силу.

# Установка Slovo на Android

## APK из GitHub Releases

1. Откройте страницу [последнего релиза](https://github.com/Dirty-Snake/slovo-app/releases/latest).
2. В разделе **Assets** скачайте файл с расширением `.apk`.
3. Откройте скачанный файл на Android-устройстве.
4. Если Android запросит разрешение, разрешите установку приложений из этого источника.
5. Завершите установку и откройте Slovo.

APK публикуется из профиля `preview` и предназначен для прямой установки. Файл `.aab` из профиля `production` предназначен для Google Play и напрямую на телефон не устанавливается.

## Обновление

Скачайте APK более новой версии и установите его поверх текущей. При совпадающей подписи Android обновит приложение без удаления локальных данных. Учебный прогресс и настройки также синхронизируются с аккаунтом.

Скачивайте приложение только из раздела Releases этого репозитория.

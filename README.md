# Slovo

Slovo — приложение для изучения слов и предложений с интервальными повторениями.

## Возможности

- словарь с переводами, ударениями, примерами и грамматическими формами;
- сербская латиница и кириллица, а также поддержка других языков;
- интервальные повторения с выбором языка и направления карточек;
- уроки на основе предложений;
- наборы слов, фильтры, импорт JSON и JSONL;
- синхронизация прогресса и настроек между устройствами.
- проверка новых Android-версий через официальный публичный GitHub Release.
